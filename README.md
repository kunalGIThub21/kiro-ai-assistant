# KIVO - Autonomous Personal AI Assistant ⚡
> **Developed with passion by Kunal Tandon** ✦

KIVO is an ultra-modern, 24/7 personal AI assistant application engineered to streamline daily workflows, automate tasks, write code, and generate AI art for free.

🌐 **Live Web Application:** [https://kivo-ai-assistant.vercel.app](https://kivo-ai-assistant.vercel.app)

## ✨ Key Features & Capabilities

- **Zero-Friction Access:** No account or passwords required. Enter your name to chat immediately with personalized greetings.
- **Iconic Branding:** Custom futuristic Cyber-Nexus logo with dynamic glowing pulse animations.
- **Multimodal AI Vision:** Upload any photo or document for instant intelligent visual analysis.
- **Dual Conversation Modes:** 
  - 🇮🇳 **Hinglish Mode:** Casual, natural Hinglish conversation.
  - 💻 **Coding Mode:** Senior architect code generation and deep technical explanations.
- **AI Art Studio:** Instant 4K AI image generation with aspect ratio toggles (1:1, 16:9, 9:16) and art style presets (Photoreal, Anime, 3D Pixar, Cyberpunk).
- **Creator Recognition:** KIVO honors its creator and visionary boss, **Kunal Tandon**, with comprehensive praise across all normal chat queries.
- **Voice Input with Waveform:** Google 4-color animated audio equalizer waveform with manual transcript editing before sending.
- **PWA Ready:** Installable on Android and iOS straight from the browser as a standalone web app.
- **Privacy & Speed:** 100% client-side `localStorage` data persistence with zero database latency.
