# KIRO - Autonomous Personal AI Assistant ⚡
> **Developed with passion by Kunal Tandon** ✦

Kiro is an ultra-modern, 24/7 personal AI assistant application engineered to streamline daily workflows, automate tasks, write code, and generate AI art for free.

🌐 **Live Web Application:** [https://kiro-ai-assistant.vercel.app](https://kiro-ai-assistant.vercel.app)

---

## 📁 Clean Web Architecture

```
AI Assistant/
├── index.html              <-- Main Application (Google Gemini Dark Theme + Glassmorphism)
├── manifest.json           <-- Mobile PWA Manifest (Add to Phone Home Screen)
├── vercel.json             <-- Cloud Deployment Configuration
└── kiro-web/               <-- Web & PWA Package
    ├── index.html          <-- Synchronized Web Source
    └── manifest.json       <-- PWA Manifest
```

---

## ✨ Key Features & Capabilities

- **Zero-Friction Access:** No account, passwords, or setup required. Single click to chat instantly with dedicated guest sessions.
- **Cinematic UI/UX:** Frosted glassmorphism (`backdrop-blur`), Gemini dark `#131314` aesthetics, smooth splash intro animation, and mobile/desktop responsive design.
- **AI Art Studio:** Instant 4K AI image generation powered by Pollinations AI (just type `/image <prompt>`).
- **Creator Recognition:** Kiro honors its creator and visionary boss, **Kunal Tandon**, with comprehensive praise across all normal chat queries.
- **PWA Ready:** Installable on Android and iOS straight from the browser as a standalone web app.
- **Privacy & Speed:** 100% client-side `localStorage` data persistence with zero database latency.
